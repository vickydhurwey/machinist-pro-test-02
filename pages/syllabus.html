📘 01. Trade Theory

UNIT 01

Workshop Safety एवं Housekeeping

  • कार्यशाला में सुरक्षा के नियम
  • व्यक्तिगत सुरक्षा उपकरण (PPE)
  • अग्निशामक यंत्र एवं प्राथमिक उपचार
  • 5S और कार्यस्थल की सफाई
  • कार्यशाला में दुर्घटनाओं से बचाव
UNIT 02

Basic Fitting एवं Hand Tools

  • Fitting Shop का परिचय
  • Bench Vice और Hand Tools
  • Marking, Hacksawing और Chiselling
  • Filing और विभिन्न प्रकार की Files
  • Drilling, Reaming और Tapping का परिचय
UNIT 03

Measuring Instruments

  • Steel Rule और Try Square
  • Vernier Caliper
  • Outside एवं Inside Micrometer
  • Dial Test Indicator
  • Bevel Protractor
  • मापन की शुद्धता और Least Count
UNIT 04

Fits एवं Tolerances

  • Basic Size और Actual Size
  • Limits और Tolerances
  • Clearance Fit
  • Interference Fit
  • Transition Fit
  • विभिन्न प्रकार के फिट का उपयोग
UNIT 05

Lathe Machine

  • Lathe Machine का परिचय एवं उपयोग
  • मुख्य भाग और उनके कार्य
  • Bed, Headstock और Tailstock
  • Carriage, Chuck और Lead Screw
  • Lathe Machine के प्रकार
  • Work Holding Devices
UNIT 06

Cutting Tools एवं Tool Geometry

  • Single Point Cutting Tool
  • Tool के मुख्य कोण
  • Rake Angle और Clearance Angle
  • High Speed Steel और Carbide Tools
  • Cutting Tool का रखरखाव
UNIT 07

Lathe Operations

  • Facing और Plain Turning
  • Step Turning और Taper Turning
  • Drilling और Boring
  • Grooving और Parting
  • Chamfering और Knurling
  • Reaming और Thread Cutting
UNIT 08

Drilling, Reaming एवं Tapping

  • Drilling Machine का परिचय
  • Drill के प्रकार और भाग
  • Twist Drill
  • Reamer और Reaming
  • Tap एवं Die
  • Internal और External Thread
UNIT 09

Thread एवं Taper

  • Metric Thread
  • V-Thread और Square Thread
  • Thread Pitch
  • Thread Cutting का सिद्धांत
  • Taper एवं Angular Components
UNIT 10

Slotting Machine

  • Slotting Machine का परिचय
  • मुख्य भाग एवं कार्य
  • Ram और Table
  • Slotting Operations
  • मुख्य उपयोग
UNIT 11

Milling Machine एवं Indexing

  • Milling Machine का परिचय
  • मुख्य भाग और प्रकार
  • Plain एवं Face Milling
  • Angular और Form Milling
  • Gang एवं Straddle Milling
  • Indexing का परिचय
UNIT 12

Grinding Machine

  • Grinding का परिचय
  • Surface Grinding Machine
  • Cylindrical Grinding Machine
  • Grinding Wheel के प्रकार
  • Wheel के मुख्य गुण
  • Grinding में सुरक्षा

व्यावहारिक प्रशिक्षण के मुख्य कार्य

  • Thread Cutting और Taper Turning

  • Milling और Indexing का अभ्यास
  • Surface एवं Cylindrical Grinding

Engineering Drawing के मुख्य विषय

  • Dimensioning

  • Isometric Drawing

  • क्षेत्रफल और आयतन
